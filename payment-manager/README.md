# 仕入支払い管理

各社からの請求書の金額を部署ごとに入力・管理し、ネットバンキング取込用の振込データ(全銀形式)を作成できる、ブラウザだけで動く仕入支払い管理ツールです。

## できること

- **請求入力**: 部署タブ・対象年月で分けて、取引先ごとの請求額・繰越額・支払額・備考を入力
- **振込データ作成**: 対象年月の未払い分を取引先ごとに集計し、
  - 全銀協規定フォーマット(総合振込)のテキストファイルをダウンロード → 銀行のネットバンキングに取り込み
  - CSV形式でもダウンロード可能
  - ダウンロード後に対象明細を「支払済み」へ一括更新
- **経費集計**: 期間・部署を指定して、部署別/勘定科目別の合計、部署×勘定科目のクロス集計を表示・CSV出力
- **マスタ管理**: 部署、取引先(銀行振込先情報を含む)、勘定科目(税率)、自社の振込元情報を管理

## セットアップ

```bash
npm install
npm run dev       # 開発サーバー起動
npm run build     # 本番ビルド (dist/ に出力)
npm run preview   # ビルド結果をローカルで確認
npm run typecheck # 型チェックのみ
```

ビルド後の `dist/` フォルダを社内サーバーや静的ホスティングに置くだけで動作します。バックエンドサーバーは不要です。

## データの保存について

入力したデータは**このブラウザのlocalStorageにのみ**保存されます。サーバーには一切送信されません。
そのため:

- ブラウザ(端末)を変えると入力データは引き継がれません
- ブラウザのデータ消去・シークレットモードでは保存されません
- 複数人での共有データベースが必要な場合は、別途バックエンド連携への拡張が必要です

## 全銀形式(総合振込)ファイルについて

「振込データ作成」で出力する `.txt` ファイルは、全国銀行協会規定の固定長フォーマット(1レコード120バイト・Shift-JIS)で、多くの金融機関のネットバンキングの「総合振込」取込機能に対応した形式です。ただし、**銀行によって取込条件が異なる場合があります**。

- 取引先マスタで「銀行コード」「支店コード」「口座番号」「受取人名(半角カナ)」「銀行名(半角カナ)」「支店名(半角カナ)」をすべて登録した取引先のみファイルに含まれます
- 銀行コード・支店コードは、取引先から受け取った振込先指定書や、全国銀行協会の銀行コード検索などで確認してください
- 自社(委託者)の情報は「マスタ管理」→「自社情報」で登録してください。委託者コードは契約している金融機関から付与されます
- **本番の振込で使用する前に、必ず少額のテスト振込や銀行への事前確認を行ってください**

## 使い方の流れ

1. 「マスタ管理」で部署・勘定科目・取引先(銀行情報含む)・自社情報を登録
2. 「請求入力」で毎月、部署タブを切り替えながら請求書の内容を入力
3. 支払う月になったら「振込データ作成」で対象年月を選び、全銀データ or CSVをダウンロードしてネットバンキングに取り込み
4. 「経費集計」で部署別・科目別の支出状況を確認
