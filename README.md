# 販売管理ソフト

見積書・納品書・請求書・領収証の作成から、得意先/商品台帳の管理、締め処理(合計請求書の一括発行)、売掛金管理、売上集計・分析まで行える販売管理ソフトです。「販売らくだ」を参考に、そこで使える主要機能を一通り実装しています。

## 主な機能

- **伝票作成**: 見積書・納品書・請求書・合計請求書・領収証をそれぞれ作成・印刷(PDF出力はブラウザの印刷機能を利用)
- **伝票の変換**: 見積書→納品書→請求書→領収証への変換で二重入力を防止
- **得意先台帳**: 得意先の登録・編集、単価ランク・得意先別掛率・締め日/支払日の設定、CSVインポート/エクスポート
- **商品台帳**: 商品の登録・編集、複数単価(単価1〜3)・仕入原価の設定、CSVインポート/エクスポート
- **締め処理**: 対象期間・得意先を指定して未請求の納品書をまとめて合計請求書を一括発行
- **売掛金一覧**: 得意先ごとの請求額・入金額・売掛残高を集計表示
- **売上集計・分析**: 得意先別・商品別・月別の売上集計とグラフ表示
- **インボイス制度対応**: 適格請求書発行事業者登録番号の印字、税率(10%/8%/非課税)ごとの税額表示
- **設定**: 自社情報・税設定(端数処理)、データのバックアップ/復元(JSON)

## データの保存について

すべてのデータはブラウザ内(IndexedDB)に保存されます。サーバーへの送信は行いません。定期的に「設定」画面からバックアップ(JSON)を保存することをおすすめします。

## 手元のパソコンで使う

### 1. 準備するもの

- [Node.js](https://nodejs.org/)(18以上推奨)がインストールされていること
- このリポジトリを取得済みであること(`git clone` または ZIP ダウンロード)

### 2. 起動方法(かんたん)

このフォルダの中にある起動ファイルをダブルクリックするだけで、初回は必要なファイルのインストールまで自動で行い、ブラウザが自動で開きます。

- Windows: `start-windows.bat`
- Mac: `start-mac.command`
  - 初回のみ「開発元を確認できません」等の警告が出る場合、右クリック→「開く」を選んでください。

起動したウィンドウ(黒い画面)は、使っている間は閉じずにそのままにしておいてください。閉じる、または `Ctrl+C` を押すとソフトが終了します。次に使うときも同じファイルをダブルクリックするだけです。

### 3. 起動方法(コマンドで実行する場合)

```bash
npm install   # 初回のみ
npm run dev
```

表示された `http://localhost:5173/` のようなURLをブラウザで開きます。

### 4. データのバックアップ

データはブラウザ内(IndexedDB)に保存されるため、ブラウザのデータを消去したり別のパソコンに移行したりすると失われます。「設定」画面の「バックアップを保存」で定期的にJSONファイルとして保存し、わかりやすい場所(例: ドキュメントフォルダ)に保管してください。復元も同じ画面から行えます。

### 5. アップデート方法

コードを更新した場合は、起動前に一度だけ次を実行してください。

```bash
git pull
npm install
```

## ビルド(配布用の静的ファイルを作る場合)

```bash
npm run build
```

`dist` フォルダに出力されます。`npm run preview` でビルド結果を確認できます。
