# スイーツデパート物語

ニンテンドーDS「チョコッと魔女とスイーツデパート」風の経営シミュレーションゲーム。
HTML5 Canvas(フロアマップ)+ DOM オーバーレイ(会話・調合・お店・コンテストなどの
パネルUI)で構成された、クリック操作のみで完結するブラウザゲームです。

データ設計の詳細と調整可能パラメータの一覧は [`DESIGN.md`](./DESIGN.md) を参照してください。

## セットアップ

```bash
npm install
npm run dev       # 開発サーバー起動
npm run build     # 本番ビルド (dist/ に出力)
npm run typecheck # 型チェックのみ
```

## 実装済み機能

- 朝/昼/夜の時間システム(研究・会話でタイムスロットが進行)
- 18店舗・18キャラクターの配置と好感度システム(Lv1〜5)
- 好感度上昇で発生する汎用イベント(お悩み相談 / お手伝いミニゲーム)× 72件
- 素材+レシピによるスイーツ調合、成功/失敗判定、F〜Sランクの習熟度成長
- 自分の店での接客(売上シミュレーション)とライバル店との月間売上競争
- 年1回・全5段階のコンテストとエンディング(スタッフロール)
- localStorage によるセーブ/ロード
