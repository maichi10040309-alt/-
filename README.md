# 介護用品レンタル請求システム

介護用品レンタルの請求業務を効率化するためのブラウザアプリです。営業担当が
入力する「月次の利用状況」を自動で4か月分ずつ集計し、そのまま印刷できる
請求書として発行できます。

これまでExcelとマクロで運用していた業務を置き換えることを目的としています。

- 介護保険品目(単位数×利用者負担割合)と自費品目の両方に対応した自己負担額の自動計算
- 非課税/課税を分けた月次・請求書ごとの金額集計
- 既存のExcel(「保険(在宅)」「自費(在宅)」シート形式)からの一括取り込み
- 3月・7月・11月始まりの固定カレンダーで4か月ごとの請求金額を自動計算
  (例: 7〜10月分は11月請求)
- ワンクリックで請求書の下書き作成・発行・印刷
- 利用者の新規・変更・終了・休止・再開などの経緯を記録する変更履歴
- 過去の提供月の実績を後日追加請求できる「月遅れ等の調整」
- 都度現金払いの方は自動請求対象から除外、途中解約などで4か月そろわない
  場合の早期請求にも対応。入金があれば請求書ごとに「入金済み」を記録可能
- 介護保険品目と自費品目の両方をレンタルしている方は、保険分・自費分を
  同じテンプレートの別々の請求書として発行
- 画面はホーム / 月次利用入力 / 請求書 / 利用者マスタ / レンタル品目マスタ
  の5メニューのみとし、ボタンを絞ってシンプルにしています

データはSupabase(共有データベース)に保存され、複数のパソコンから同じ
データを見る・入力することができます。接続情報は`src/supabaseClient.ts`に
設定済みです。テーブル定義は[`supabase/schema.sql`](./supabase/schema.sql)
を参照してください。

## セットアップ

```bash
npm install
npm run dev       # 開発サーバー起動
npm run build     # 本番ビルド (dist/ に出力)
npm run typecheck # 型チェックのみ
```

## 基本的な使い方

### 初回: 既存Excelからの一括取り込み

「月次利用入力」画面の「Excelから一括取り込み」から、毎月使っている運用Excel
(「保険(在宅)」「自費(在宅)」シートを含む.xlsx/.xlsm)と対象年月を選ぶだけで、
利用者マスタと当月の利用状況をまとめて取り込めます。ファイルはブラウザ内だけで
読み込まれ、外部には送信されません。2か月目以降も、同じ形式のExcelを毎月
取り込むだけで運用できます(手入力も引き続き可能です)。

### 手入力の場合

1. 「利用者マスタ」で利用者を登録します。「利用者負担割合」(1割/2割/3割/生保)は
   介護保険品目の自己負担額の自動計算に使われます。請求サイクルは全利用者共通
   (3月・7月・11月始まり)なので、利用者ごとの設定は不要です。都度現金払いの
   方は「請求方法」を「都度現金」にすると、自動の請求対象から除外されます。
2. 「レンタル品目マスタ」で品目を確認・調整します。介護保険品目は単位数×負担割合
   で自動計算され、自費品目は金額を直接入力します。
3. 毎月、「月次利用入力」で利用者・対象月を選び、その月にレンタルしている
   品目と数量(保険品目は単位数)、非課税/課税の区分を入力して保存します。
   「前月の内容をコピー」で前月と同じ内容ならワンクリックで複製できます。
   「一覧」タブで、全利用者の入力状況(未入力/入力済み)と保険品目・自費品目
   ごとの金額を一覧確認できます。
4. 7〜10月分は11月、11〜2月分は3月、3〜6月分は7月というように、締め月の
   翌月になると「請求書」画面の「請求対象(未請求)」欄に自動で表示されます。
   保険品目・自費品目の両方をレンタルしている利用者は、保険分・自費分の
   2行に分かれて表示されます(どちらか一方だけの方は1行のみ)。
   「請求書を作成」→内容確認(非課税/課税の内訳付き)→「発行済みにする」→
   「印刷」の流れで請求書を発行します(保険分・自費分とも同じテンプレートを
   使います)。複数まとめて作成したい場合は、各行のチェックボックスを
   選んで「選択した請求書をまとめて作成」からまとめて下書き作成できます。
   一覧に出てこない利用者がいる場合は、「この一覧に表示されない利用者を
   確認」を開くと、都度現金払い/未入力/進行中/請求済みなど、表示されない
   理由を利用者ごとに確認できます。導入前から続けている利用者などで、
   直近より前の締め済み未請求サイクルが残っている場合は「過去の未請求分」
   に分けて表示されます(旧Excel等で既に請求済みのことも多いため、内容を
   確認してから作成してください)。利用者マスタの「最新請求書」列からも、
   各利用者の一番新しい請求書をすぐに開けます。
5. 過去の提供月の実績が後日わかった場合は、「請求書」画面の「月遅れ等の調整」
   から追加できます。本来の提供月と、どの請求サイクルにまとめて計上するかを
   指定すると、その請求書に別枠(月遅れ等の調整)として反映されます。
   途中解約などで4か月そろう前に請求したい場合は、「早期請求」から利用者を
   選ぶと、その時点までの実績で請求書を作成できます(実績のある月だけが
   印字されます)。都度現金払いや早期請求など、締めを待たず入金があった
   場合は、請求書詳細画面の「入金済みにする」から入金日を記録できます
   (発行状況とは別に管理され、あとから「未入金に戻す」ことも可能です)。
6. 利用者の新規・変更・終了・休止・再開などの経緯は、「利用者マスタ」の
   「変更履歴」タブに記録できます(請求計算には影響しません。利用者の状態は
   引き続き利用者編集画面の「状態」欄で管理します)。
7. 左メニュー下部の「事業所情報設定」で自社名・住所・振込先などを設定すると
   請求書に印字されます。
