# 介護用品レンタル請求システム

介護用品レンタルの請求業務を効率化するためのブラウザアプリです。営業担当が
入力する「月次の利用状況」を自動で4か月分ずつ集計し、そのまま印刷できる
請求書として発行できます。

これまでExcelとマクロで運用していた業務を置き換えることを目的としています。

- 月ごとの利用状況入力 → 4か月ごとの請求金額を自動計算
- ワンクリックで請求書の下書き作成・発行・印刷
- 画面はホーム / 月次利用入力 / 請求書 / 利用者マスタ / レンタル品目マスタ
  の5メニューのみとし、ボタンを絞ってシンプルにしています

データはブラウザの localStorage に保存されます(サーバー不要)。

## セットアップ

```bash
npm install
npm run dev       # 開発サーバー起動
npm run build     # 本番ビルド (dist/ に出力)
npm run typecheck # 型チェックのみ
```

## 基本的な使い方

1. 「利用者マスタ」で利用者を登録します。「請求サイクル起算月」がその方の
   4か月区切りの起点になります(例: 4月起算なら 4〜7月分→8〜11月分→…)。
2. 「レンタル品目マスタ」でレンタル品目と月額単価を確認・調整します
   (代表的な介護用品を初期データとして登録済みです)。
3. 毎月、「月次利用入力」で利用者・対象月を選び、その月にレンタルしている
   品目と数量を入力して保存します。「前月の内容をコピー」で前月と同じ内容
   ならワンクリックで複製できます。
4. 4か月分がそろい請求月になると、「請求書」画面の「請求対象(未請求)」欄に
   自動で表示されます。「請求書を作成」→内容確認→「発行済みにする」→
   「印刷」の流れで請求書を発行します。
5. 左メニュー下部の「事業所情報設定」で自社名・住所・振込先などを設定すると
   請求書に印字されます。
